# Project Title

---

- ESP32 EXPANSION BOARD

  ---

  ## Project Description
An ESP32 Expansion Board designed to simplify connections between the ESP32 microcontroller and external sensors, modules, and actuators. The board provides organized GPIO access, power distribution, and easy prototyping for IoT and embedded system projects.

---


## Features
- GPIO pin breakout
- G-V-S pin layout
- 3.3V and 5V power support
- Easy sensor and module connection
- Compact PCB design

  ---


## Components Used
- ESP32 Development Board
- Pin Headers
- Voltage Regulator
- Capacitors
- PCB
